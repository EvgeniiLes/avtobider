# Автобидер

Сервис, который сам ведёт рекламу малого бизнеса (салон, студия и подобное) в Яндекс Директе. Владелец рассказывает о бизнесе и задаёт бюджет. Сервис создаёт объявления, следит за результатом, останавливает слабое, усиливает сильное, сравнивает пограничное (A/B-тесты) и объясняет каждое действие простыми словами с возможностью отмены.

Рабочий экземпляр: https://addtracker.ru

## Что умеет

| Требование задания | Где в сервисе |
|---|---|
| Вход и регистрация | e-mail и пароль или «Войти через Яндекс ID» (`app/routes/auth.py`, `yandex_login.py`) |
| Подключение своего рекламного кабинета без правки кода | «Подключения» → «Подключить Яндекс Директ»: код на `ya.ru/device`, токены вводить не нужно (`direct_connect.py`). Параметры приложения Яндекса только в настройках |
| Описание бизнеса, бюджет, запуск | «Бизнес» (форма, логотип, фото, видео, Яндекс Карты, цвета, тон) и «Главная» → «Создать рекламу» с предпросмотром плана (`launch.py`) |
| Кампании с широким охватом и небольшими бюджетами | Жёсткий недельный лимит у кампании, автотаргетинг и ключевые фразы из профиля аудитории, минус-слова по нише. По умолчанию в показ идёт одно объявление, остальные запасные: по ним сравнивают подачи и заменяют слабое. Можно пустить в показ несколько, каждое по желанию в своей кампании (`app/direct/launch.py`, `negatives.py`) |
| Отключение слабой и рост сильной рекламы | Движок: оценка вероятности «окупается» по обращениям, +20% бюджета сильным, остановка слабых (`app/engine/`, `docs/algorithms.md`) |
| A/B-тесты с выводом и применением решения | Для пограничных объявлений создаётся второй вариант, вывод по статистике, проигравший останавливается (`engine/cycle.py`) |
| Расходы, обращения, клиенты, цена клиента | «Главная» и «Результаты»: график по дням, данные Директа и цели Метрики, клиенты отмечаются владельцем (`direct/runner.py`, `routes/stats.py`) |
| Соблюдение бюджета | Недельный лимит у каждой кампании в Директе, раздаём не больше 90% бюджета, при превышении всё останавливается, проверка при каждом цикле |
| История изменений, причины, откат | «История»: причина простыми словами, «Отменить», режим «сначала спрашивать меня» |
| Картинки и видео | «Объявления»: тексты через Claude, картинки и видео через fal.ai, баннеры с заголовком и логотипом, загрузка баннеров и видео в Директ к конкретному объявлению |
| Уведомления в Telegram | Привязка кнопкой на сайте («Подключения»), отчёт дня, тревоги и сообщения о проверке объявлений: принято или отклонено с причиной простыми словами и что делать (pp/notifier.py, pp/direct/moderation.py). Токен бота только в .env |
| Маркировка рекламы | Директ метит сам. «Данные рекламодателя» (вид плательщика, ИНН, имя) вносятся прямо на сайте через API Директа (`Clients.update`), ИНН у нас не хранится; если данные уже внесены в кабинете, сайт видит это сам |

Схема всей системы с рисунками: `docs/architecture.html` (открывается в браузере). Подробнее: `docs/algorithms.md` (правила решений), `docs/platforms.md` (площадки), `docs/database.md` (база).

## Как это устроено
- **Сайт** (FastAPI, SQLite, страницы на HTML и JS без сборки): `app/main.py`, `app/web/`.
- **Фоновый процесс** `app/worker.py`: каждые 30 минут забирает статистику из Директа и принимает решения.
- **Площадки** подключаются через общий интерфейс `app/platforms/base.py`: сейчас Яндекс Директ (`platforms/direct.py`) и симулятор «пример данных» (`platforms/simulator.py`).
- Токены кабинетов хранятся в базе только в зашифрованном виде (ключ `SECRET_KEY`).

## Запуск на своём компьютере (Windows, PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env   # впишите ключи
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

Сайт: http://localhost:8000. Тесты: `.\.venv\Scripts\python.exe -m pytest`.

## Развёртывание на сервере
Пошаговая инструкция: `docs/deployment.md` (сервер Ubuntu/Debian, домен, HTTPS, две службы и ежедневная резервная копия, настройки приложений Яндекса).

## Настройки
Все ключи задаются переменными окружения (шаблон: `.env.example`). Файл `.env` в репозиторий не попадает. Свои приложения Яндекса подставляются только там: `YANDEX_CLIENT_ID` и `YANDEX_CLIENT_SECRET` (доступ к Директу и Метрике), `YANDEX_LOGIN_CLIENT_ID` и `YANDEX_LOGIN_CLIENT_SECRET` (вход через Яндекс ID).

## Ограничения (честно)
- Подключены только Яндекс Директ и Метрика. VK Реклама, Авито и другие площадки не подключены: нужны ваши приложения и доступы на этих площадках.
- Видео уходит в Директ к объявлению кнопкой «Отправить в Директ» (`app/direct/videos.py`): проверено на заглушке Директа, на живом кабинете ещё нет. Комбинаторным объявлениям видео пока не отправляется.
- Яндекс считает статистику с задержкой до трёх дней: решения опираются на устоявшиеся данные.
- Песочница Директа закрыта Яндексом с 15.07.2026, поэтому проверка идёт на реальном кабинете, а логика решений отрабатывается и на примере данных.
