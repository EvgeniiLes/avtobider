# Автобидер

Сервис, который сам ведёт рекламу малого бизнеса в Яндекс Директе: владелец рассказывает о бизнесе и задаёт бюджет, сервис создаёт кампании, отключает слабую рекламу, усиливает сильную, проводит A/B-тесты и объясняет каждое изменение простыми словами с возможностью отката.

Статус: в разработке.

## Что уже есть

- Приложение «Автобидер» зарегистрировано в Яндекс OAuth (тип «Только API»), заявка на полный доступ к API Директа одобрена.
- `docs/direct-api-spec-and-mockups.pdf`: спецификация приложения и макеты экранов (отправлялись вместе с заявкой).

## Структура

| Папка | Что внутри |

## Запуск на своём компьютере (Windows, PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env   # впишите токен в YANDEX_DEV_TOKEN
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

Сайт откроется на http://localhost:8000. Тесты: `.\.venv\Scripts\python.exe -m pytest`.

## Что уже работает

- Регистрация и вход по e-mail и паролю (пароль хранится в виде хеша scrypt, сессия в cookie).
- Подключение рекламных кабинетов Яндекс Директа: токен проверяется запросом `Campaigns.get` и сохраняется в базе только в зашифрованном виде (ключ `SECRET_KEY`). Другой кабинет подключается без правки кода.
- Список кампаний простым языком и остаток баллов Директа. Переключатель «Тестовый режим» выбирает песочницу или боевой кабинет.
- Каждый пользователь видит только свои кабинеты.

## Настройки

Все ключи задаются переменными окружения (шаблон: `.env.example`). Файл `.env` в репозиторий не попадает.
