# Автобидер

Сервис, который сам ведёт рекламу малого бизнеса в Яндекс Директе: владелец рассказывает о бизнесе и задаёт бюджет, сервис создаёт кампании, отключает слабую рекламу, усиливает сильную, проводит A/B-тесты и объясняет каждое изменение простыми словами с возможностью отката.

Статус: в разработке.

## Что уже есть

- Приложение «Автобидер» зарегистрировано в Яндекс OAuth (тип «Только API»), заявка на полный доступ к API Директа одобрена.
- `docs/direct-api-spec-and-mockups.pdf`: спецификация приложения и макеты экранов (отправлялись вместе с заявкой).

## Запуск на своём компьютере (Windows, PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env   # впишите токен в YANDEX_DEV_TOKEN
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

Сайт откроется на http://localhost:8000. Тесты: `.\.venv\Scripts\python.exe -m pytest`.

## Что уже работает

- Регистрация и вход по e-mail и паролю (пароль хранится в виде хеша scrypt, сессия в cookie).
- Подключение рекламных кабинетов Яндекс Директа: токен проверяется запросом `Campaigns.get` и сохраняется в базе только в зашифрованном виде (ключ `SECRET_KEY`). Другой кабинет подключается без правки кода.
- Страница «Мой бизнес»: описание (название, чем занимаетесь, рассказ, город, сайт), стиль рекламы (тон и два цвета) и деньги (средний чек, цена клиента, бюджет на неделю). До 5 бизнесов на аккаунт.
- Загрузка файлов для рекламы: логотип (один), фото бизнеса с пометкой «Помещение, Наши работы, Команда, Товар или услуга, Другое» (до 20) и видео (до 3, MP4, MOV, WEBM до 100 МБ). Картинки проверяются и перекодируются, скрытые данные съёмки (EXIF) удаляются. Файлы лежат в `data/uploads/` и отдаются только владельцу.
- Пример данных: симулятор площадки с честной пометкой «Пример данных». Запустите его на вкладке «Статистика» и прокручивайте дни: сервис сам оценивает объявления, останавливает слабые, добавляет 20% бюджета сильным, сравнивает пограничные (A/B-тест) и не тратит больше недельного бюджета.
- Статистика: расход, обращения, клиенты, цена клиента, расход бюджета недели и оценка каждого объявления («Окупается», «Пока неясно», «Не окупается», «Собираем данные»).
- История изменений: что и почему сделал сервис простыми словами, с кнопкой «Отменить» (откат).
- Список кампаний простым языком и остаток баллов Директа. Песочница Директа закрыта Яндексом с 15 июля 2026 года, поэтому сервис работает с боевыми кабинетами.
- Каждый пользователь видит только свои кабинеты.

## Настройки

Все ключи задаются переменными окружения (шаблон: `.env.example`). Файл `.env` в репозиторий не попадает.
