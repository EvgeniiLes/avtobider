Как это сделаем в коде

  • Один файл с токенами (цвета, шрифты, отступы, радиусы). Все страницы берут значения только оттуда, поэтому не расходятся.
  • Шрифты с нашего сервера, а не из Google Fonts: быстрее и не зависит от доступности чужого сайта.
  • app.js делится на модули по разделам (обзор, объявления, результаты, материалы, настройки), общее выносится отдельно. Сейчас это один файл на полторы тысячи строк.
  • API не меняется. Меняются только вёрстка и маршруты; старые ссылки (#/creatives и другие) перенаправляются.
  • Прежняя версия остаётся на /old, пока вы не примете новую. Текущую версию сохраним в git-метке, как сделали в прошлый раз.
  • Тёмная тема делается из тех же токенов, а не отдельной раскраской.
Направление C (по вашему референсу): панель из A с крупным жирным шрифтом, пастельными плитками и капсулами. Главная называется «Главная», а не «Обзор»: открыть макет C.
Для сравнения остались два первых характера на одних и тех же экранах: A: рабочая панель (боковое меню, аккуратные рамки, один синий акцент) и B: издание (верхнее меню, крупные заголовки с засечками, зелёный акцент, без рамок). Числа в макетах условные.
