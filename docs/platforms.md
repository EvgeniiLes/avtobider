# Рекламные площадки: что умеет прямой API

Проверено 28.10.2026 по документации и репозиториям. Статус «подтверждено» значит, что я читал официальный источник; «со слов» значит, что источник сторонний; «не проверено» значит, что подтверждения нет.

## Яндекс Директ
- Адрес: `https://api.direct.yandex.com/json/v501/{сервис}`.
- Недельные бюджеты с 29.06.2026. Недельный лимит стратегии: `WeeklySpendLimit` (деньги × 1 000 000). `BudgetIncreasePercent` позволяет Директу самому поднимать бюджет, для строгого бюджета ставим 0.
- Источник: https://yandex.ru/dev/direct/doc/ru/llms-full.txt (история изменений и описание стратегий).

## VK Реклама
- Хост `ads.vk.com`. Токен: `POST /api/v2/oauth2/token.json` с `grant_type=client_credentials`, `client_id`, `client_secret`; в ответе `access_token`, `refresh_token`, `expires_in=86400`.
- Кампания: `name`, `status`, `date_start`, `date_end`, `autobidding_mode`, `budget_limit_day`, `budget_limit`, `max_price`, `objective`, `ad_groups[]` (внутри `banners[]`). `max_price=0` значит полностью автоматическое управление ставкой. Реклама подчиняется «рекламным пакетам» (`package_id`), набор полей объявления зависит от пакета.
- Картинки: `POST /api/v2/content/static.json`.
- Не подтверждено: как получить доступ к API в кабинете (со слов: «Настройки → Доступ к API», при отсутствии раздела писать в поддержку), значения `status`, лимиты частоты запросов, поддержка ссылки `t.me`.
- Источники: https://ads.vk.ru/en/doc/api/info/Quick%20start и https://ads.vk.ru/en/doc/api/info/Statistics.

## Авито Реклама
- Адреса: `https://api.avito.ru/ads/` (боевой), `https://api.avito.ru/ads-sandbox/` (песочница).
- Через API можно: читать аккаунт, баланс, кампании, группы, креативы, статистику; менять бюджет и ставку группы. Создавать и останавливать кампании, по найденным данным, нельзя. «Отключить» плохую группу можно только снижением бюджета до минимума, если площадка это допускает (минимум не проверен).
- Официальная документация: `developers.avito.ru/api-catalog/ads/documentation`. Мне она не открылась: сайт показывает проверку безопасности. Обходить её я не стал, спецификацию нужно открыть вручную из браузера.
- Источник найденного: официальный SDK https://github.com/avito-tech/avito-ads-sdk-go и сторонний https://github.com/A1-x-Tech/mcp-avito-ads.

## 2ГИС
- Открытой документации по рекламному API не найдено. Размещение идёт через менеджера или через посредников (click.ru, eLama), а посредники по заданию запрещены. Есть API данных организаций и карт, но это не реклама.
- Вывод: прямое подключение невозможно по найденным данным. Не включаем в автоматику. Если у 2ГИС окажется закрытый API для партнёров, это можно узнать только у менеджера 2ГИС.

## Решение
1. Директ: полная автоматика.
2. VK Реклама: вторая площадка с полной автоматикой.
3. Авито Реклама: режим «усиление и ослабление» (читаем статистику, меняем бюджет и ставку группы), без создания и остановки.
4. 2ГИС: вне автоматики.

Различия описываются флагами возможностей у каждого адаптера площадки (`can_create`, `can_pause`, `can_set_budget`, `can_set_bid`), а движок решений выбирает действие по этим флагам.
