# Развёртывание на сервере

Подходит чистый сервер Ubuntu или Debian с Python 3.10 или новее, 1 ядро и 1 ГБ памяти достаточно. Нужны: доступ по SSH с правами root и домен, запись A которого указывает на IP сервера.

Сервис работает как служба systemd (`autobider`), перед ним стоит nginx с HTTPS. Данные (база и загруженные файлы) лежат в `/opt/autobider/data`.

## 1. Скопируйте проект на сервер
Через git (если проект выложен в репозиторий):

```bash
git clone <адрес репозитория> /opt/autobider
```

или архивом со своего компьютера:

```bash
scp -r ./avtobider root@IP-СЕРВЕРА:/opt/autobider
```

## 2. Запустите установку

```bash
cd /opt/autobider
chmod +x deploy/install.sh
./deploy/install.sh ваш-домен.ru
```

Скрипт ставит пакеты, создаёт пользователя `autobider`, виртуальное окружение, службу и настройки nginx. Его можно запускать повторно.

## 3. HTTPS

```bash
certbot --nginx -d ваш-домен.ru
```

Сертификат продлевается сам.

## 4. Настройки (`/opt/autobider/.env`)
Откройте файл и заполните. Секреты храните только здесь, в репозиторий они не попадают.

| Переменная | Что это |
|---|---|
| `SECRET_KEY` | Ключ шифрования токенов кабинетов. Сгенерируйте: `python3 -c "import secrets; print(secrets.token_urlsafe(48))"`. Потеряете ключ: сохранённые кабинеты придётся подключить заново |
| `APP_ENV` | Оставьте пустым. Значение `development` включает кнопку «Взять токен с сервера», на боевом сервере её быть не должно |
| `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET` | Приложение в Яндекс OAuth для работы с Директом и Метрикой (тип «Для доступа к API или отладки», права `direct:api` и `metrika:read`; на доступ к API Директа для этого приложения должна быть одобрена заявка). С его помощью пользователи подключают кабинеты кнопкой «Подключить Яндекс Директ»: сервис показывает короткий код, пользователь вводит его на `ya.ru/device` и разрешает доступ. Адрес возврата у такого приложения не нужен |
| `YANDEX_LOGIN_CLIENT_ID`, `YANDEX_LOGIN_CLIENT_SECRET`, `YANDEX_REDIRECT_URI` | Приложение для входа через Яндекс ID (тип «Для авторизации пользователей», права `login:email`, `login:info`). Redirect URI: `https://ваш-домен.ru/auth/yandex/callback` |
| `WORKER_INTERVAL_MINUTES` | Как часто фоновый процесс обновляет данные из Директа и принимает решения (по умолчанию 30) |
| `ANTHROPIC_API_KEY`, `FAL_KEY` | Ключи для текстов и картинок, когда подключены |

Свои приложения вы подставляете только здесь, код менять не нужно. Ключи удобно записать скриптами `deploy/set-direct-keys.ps1` и `deploy/set-login-keys.ps1` (запускаются на вашем компьютере, секрет вводится скрытно).

После изменения: `systemctl restart autobider autobider-worker`.

## 5. Проверка

```bash
curl https://ваш-домен.ru/api/health      # {"ok":true}
systemctl status autobider autobider-worker
journalctl -u autobider -n 50
journalctl -u autobider-worker -n 50      # что делал фоновый процесс
```

Две службы: `autobider` (сайт) и `autobider-worker` (каждые N минут забирает статистику из Директа и Метрики и принимает решения). Работают независимо.

## Как проверить работу вживую
1. Войдите на сайт, опишите бизнес (город, сайт или ссылка на Яндекс Карты, бюджет, цена клиента).
2. «Рекламные кабинеты» → «Подключить Яндекс Директ»: откройте показанную страницу Яндекса, введите код и нажмите «Разрешить».
3. Вкладка «Статистика» → «Создать рекламу»: посмотрите план и подтвердите. Объявления уйдут на проверку в Яндекс.
4. После одобрения пополните счёт в Яндекс Директе (минимум 300 ₽). Показы начнутся сами.
5. Подключите счётчик Метрики и цель «обращение» (карточка на вкладке «Мой бизнес»): без неё сервис следит только за бюджетом.

## Обновление
Скопируйте новую версию кода в `/opt/autobider` и выполните:

```bash
cd /opt/autobider
.venv/bin/pip install -r requirements.txt
systemctl restart autobider
```

База обновляется сама при запуске.

## Резервные копии
Достаточно копировать папку `/opt/autobider/data` и файл `/opt/autobider/.env`. Базу можно копировать на ходу командой `sqlite3 data/app.db ".backup data/backup.db"`.

## Если что-то не работает
- Сайт не открывается: `systemctl status autobider` и `journalctl -u autobider -n 100`.
- Ошибка 502: служба не запущена, смотрите журнал.
- Загрузка большого видео обрывается: проверьте `client_max_body_size` в `/etc/nginx/sites-available/autobider`.
- Вход «зависает» или пропадает после перезагрузки страницы: проверьте, что открываете сайт по HTTPS и что nginx передаёт заголовок `X-Forwarded-Proto` (он уже есть в нашем конфиге).
